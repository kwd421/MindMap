# Result artifacts

Committed files are compact exploratory outputs generated by the committed scripts.

The full query-level file `epistemic_branch_pilot_query_results.csv` is intentionally not versioned because it is large and deterministically reproducible with:

```bash
python experiments/epistemic_branch_pilot.py
```

The compressed `epistemic_branch_pilot_per_scenario.csv.gz` is the independent-unit artifact used for clustered analysis. The robustness script emits all replicate-level outputs; compact summaries and the compressed run table are committed.

All results are structured-oracle mechanism/conformance evidence, not end-to-end conversational accuracy.
