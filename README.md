# MindMap — Lifecycle-Correct Agent Memory Research

Research repository for long-horizon agent memory inspired by the **MindMap** terminology used in the Korean localization of the *Girls' Frontline / Neural Cloud* setting.

`MindMap` is an engineering term here, not a claim of canonical equivalence to one fictional data structure.

## Current research question

How should an agent-memory system reconstruct, at a specified valid time and system time:

- branch-local world state;
- what one cognitive instance was exposed to;
- what is currently available to that instance;
- what it believes, rejects, doubts, or infers;
- whether a memory is direct, replicated, restored, copied, reported, or inferred;
- what a requester may receive;
- which active source path justifies the answer;

especially after world forks, cognitive copies, restores, selective transfers, adoption decisions, sealing/forgetting, revocation/deletion, and independent re-derivation.

## Reconciliation result

The broad combination of temporal memory, provenance, graphs, hierarchy, rollback, and access control is prior art and is not the central novelty claim.

A further result constrains the experiment:

> A complete generic bitemporal event ledger carrying the same semantic operations can represent the same finite oracle states as the typed schema. Schema normalization alone cannot create oracle answer superiority.

The research is therefore split into:

1. **Semantic conformance** — independent declarative gold; complete equal-information implementations are expected to agree.
2. **Lifecycle enforcement** — invalid-transition detection, fault localization, deletion/revocation residue, attribution errors, crash/replay consistency, and cost.
3. **Extraction/generalization** — raw-language extraction and downstream reconstruction on held-out lifecycle topology families.

## Required next implementation

The next accepted artifact is a small independent-gold lifecycle suite with:

- fork-valid-time versus late-import controls;
- unsynchronized same-principal replicas;
- identity forks and attributed copies;
- receive/adopt/reject separation;
- historical exposure versus current availability;
- explicit snapshot manifests and recovery gaps;
- cross-world proposition scope;
- revocation/deletion and alternative support;
- missing, duplicate, reordered, corrupted, and partial-commit faults.

A raw-dialogue track follows only after semantic fixtures, system contracts, topology splits, and analysis are frozen.

## Interpretation rule

A deterministic resolver matching labels generated by the same rules is a **self-consistency smoke test**. A fixed hand-authored truth table is a **semantic discriminability test**. Neither is an estimate of real conversational accuracy or an architecture-comparison effect size.
